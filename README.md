# AI Agents — Your Autonomous Workforce

**Built by [Girish Lade](https://ladestack.in)**

A sleek, single-page marketing website for an AI-agents platform — "your autonomous workforce". A landing page showcasing how autonomous AI agents work: real-time updates, continuous learning from data and feedback, and agents that perform tasks on your behalf.

## ✨ Features

- **Hero section** — bold headline and product pitch
- **How-it-works** — watch an agent work with real-time updates
- **Capabilities showcase** — what the agents can do
- **Learning loop** — agents improve continuously from new data and user feedback
- **Fully responsive** — works on desktop and mobile
- **100% client-side** — single HTML file, no build step, no dependencies

## 🛠️ Tech Stack

- Plain **HTML5**, **CSS3**, vanilla **JavaScript**
- No frameworks, no build step

## 🚀 Quick Start

Just open `index.html` in any browser:

```bash
git clone https://github.com/girishlade111/AI-Agents-Website.git
cd AI-Agents-Website
# open index.html in your browser
```

Or serve locally:

```bash
npx serve .
```

## 📁 Project Structure

```
index.html     # the whole site: markup, styles, and script in one file
```
